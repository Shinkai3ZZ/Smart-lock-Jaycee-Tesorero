# Smart-Lock-Jaycee-Tesorero

## Description
The Smart Lock is a mobile application designed to remotely control and monitor a smart door lock using Internet of Things (IoT) technology. The application allows users to lock and unlock doors, view real-time lock status, and enhance home security through a connected system. This project aims to provide a convenient, secure, and modern alternative to traditional door locks.

## Technologies Used
- **Flutter** – for building the cross-platform mobile application  
- **Dart** – programming language used in Flutter  
- **IoT** – smart lock hardware integrated with sensors and microcontrollers  
- **Cloud Computing** – Firebase (Authentication & Realtime Database / Firestore)

## Features
- User authentication (login and registration)
- Remote lock and unlock control
- Real-time lock status monitoring
- Cloud-based data storage and synchronization
- User-friendly mobile interface
- Secure communication between the app and IoT device
